About Our Project

AI Real-Time Micro-Expression and Lie Analyzer is an AI-based project designed to analyze facial expressions and identify possible emotional changes in real time.

Our Features

😊 Micro-Expression Detection

Detects subtle facial expression changes.

🤖 AI-Based Analysis

Uses AI techniques to analyze facial expressions.

📷 Real-Time Camera

Allows real-time facial analysis using a camera.

📊 Result Display

Displays the analysis results clearly to the user.

How It Works

1. 📷 Camera Input

The system captures the user's facial expressions through the camera.

2. 👤 Face Detection

The system detects and tracks the face from the camera input.

3. 🤖 AI Analysis

AI analyzes facial movements and expression changes.

4. 📊 Result

The analysis result is displayed on the screen.
